子代理（Sub-agent）UI 原型

DeepAgents task 工具在对话流中的可视化 · 三种形态

事件源：tool.called / tool.result (name="task") ｜ 树形结构参考 Claude-Code-Agent-Monitor 的 parent_agent_id 递归渲染 ｜ 视觉沿用现有设计 token（--paper / --line / --brand），零 radix 手写风格。 卡片 header 可点击折叠。

A 形态一：对话流内的子代理卡片（推荐主形态）

子代理在聊天里渲染为一张独立卡片（比普通工具卡信息密度更高）：header = 图标 + 名称 + 描述 + 状态徽章 + 耗时； 展开后是子代理自己的执行步骤；子代理再派生的孙代理以「左竖线 + 缩进」嵌套呈现。

B 形态二：代理执行树（索引）＋ 右侧详情面板（纵深）

树是索引，详情在右侧面板打开——与「点产物卡 → 右侧开 Processor」是同一交互心智。 点击左侧任意代理节点查看它的执行详情（概要 / 步骤 / 返回结果 / 错误）； 详情里的「在对话中定位」会滚动到对话流中的对应卡片并高亮闪烁。

# AI 新闻调研（多子代理编排）

## 概述

先与用户确认调研范围（哪些厂商、有无侧重），再并行派发对应数量的 `news-researcher`
子代理，最后汇总成对比报告。本技能是 HITL + 多子代理编排的全链路测试载体：
**多选问答卡（ask_human）→ 派发审批卡（task 门禁）→ 子代理执行 → 汇总**。

## 执行流程

### 第 0 步：ask_human 确认调研范围

派发前先调 `ask_human` 让用户挑选调研对象：

- question（两段式：第一行问题、换行后一句影响说明）：
  `这次调研哪些厂商？（可多选，并可在输入框补充调研侧重）
  选定多少家就并行派发多少个子代理，未选中的不调研。`
- options：`OpenAI；Google DeepMind；Anthropic`
- multiple：`true`（多选）

用户回答形如「已选：OpenAI；Anthropic
补充：重点关注模型发布」——按**已选厂商**派发子代理，**补充文字**作为每家调研的
额外侧重写进 description。回答没有「已选：」时（用户纯文字回答），自行理解其指的
厂商；完全无法判断时默认三家。

### 第 1 步：等待派发审批

`task` 派发配置了审批门禁：发出 task 调用后任务会**暂停**，前端弹出确认卡
（列出待派发的调研任务），用户点「批准」才会执行。批准前子代理不会运行；
若用户「拒绝」并给了理由，按理由调整后再继续（如减少厂商、改侧重、或放弃并说明），
**不要原样重发相同的 task 调用**。

### 第 2 步：并发派发子代理

对每个已选厂商，在**同一条消息里一次性发出 task 工具调用**（subagent_type 都是
`news-researcher`，多个调用必须写在同一条 assistant 消息里并行执行，不要派一个等一个）。
description 模板（含用户的补充侧重，如有）：

1. OpenAI：调研 OpenAI 最新动态。建议先抓 `https://openai.com/news/`，页面信息不足时补抓其中指向的子页面。
2. Google DeepMind：调研 Google DeepMind 最新动态。建议先抓 `https://blog.google/technology/google-deepmind/`。
3. Anthropic：调研 Anthropic 最新动态。建议先抓 `https://www.anthropic.com/news`。

每个 description 里注明输出格式：3-5 条，每条含 日期、标题、一句话摘要、来源 URL。

### 第 3 步：主线程汇总

子代理报告回传后，输出中文汇总：

- 按**实际调研的厂商**分节呈现，每家保留 3-5 条要点；
- 调研了两家及以上时，结尾加一小节「跨厂商趋势」（2-3 句，对比共同方向）；只调研一家时省略。

## 注意事项

- 主线程**不要自己调 fetch_url**——抓取是子代理的活，主线程只负责派发与汇总。
- 子代理抓取失败会自行降级（基于模型知识输出并注明「未能联网核实」），主线程照常汇总即可。
- 调研范围是「最新动态」（模型/产品/政策/研究），不含财报类新闻，除非用户明确要求。

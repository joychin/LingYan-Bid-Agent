# 节：评分标准（evaluation）

忠实提取评审方法、评分项、分值、评分要点、证明材料、加减分项与冲突。输出
`work/analysis/evaluation.md`。

## 提取范围

评标办法/评分办法章节（通常为独立章或附件，用 outline 定位 + grep 逐词检索：评分、评标、得分、分值——grep 是字面匹配，不支持 `|` 合并）。

## 判定边界

- **资格门槛不是评分项**，除非原文明确把它计入总分。
- 评标表格可能跨页/合并单元格/抽取失真——**逐行核对**，发现表格断裂时按相邻行语义
  拼接并在出处列注明「表格跨页拼接」；拼不上的行宁可弃掉并登记澄清，不编数值。
- 不修正原文冲突（两处分值不一致 → 冲突条目两条都列）；不预设技术/商务/价格分类；
- 不把「如何得高分」的策略建议写进结果。

## 分值类型标注

每条评分项在「分值」列写值，格式视原文而定（union 七类）：
纯数值（10）/ 区间（8~12）/ 公式（(报价-最低价)/最低价×30）/ 定性（优/良/中/差）/
通过制（满足得基础分）/ 带符号加减（+2 或 -5）/ 未知（原文缺失或不可读）。

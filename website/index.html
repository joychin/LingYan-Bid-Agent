常见问题

关于模型、联网和交付格式的实际问题。

需要联网才能用吗？

解析、存储、文档生成都发生在你电脑上；只有调用你配置的大模型时才需要联网。

用什么大模型？

自带 API Key，支持 DeepSeek、智谱、Kimi、通义等 OpenAI 兼容接口，也可以按每条对话随时切换模型。

支持哪些操作系统？

目前提供 Windows 与 macOS 安装包，可在 GitHub Releases 页面下载。

公司资料要每次重新传吗？

不用。营业执照、资质证书、合同案例、过往标书这些传一次进素材库和知识库，写任何新标书时都会按需检索。素材引用保持原文，写作时改写适配本项目。

生成结果是 Word 吗？我能修改吗？

是标准 .docx，带修订标记和批注。你在 Word 里直接改，改过的内容它后续写其他章节时也会参考。

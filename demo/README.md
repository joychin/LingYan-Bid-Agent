# 演示录制数据包（脱敏）

录制产品演示视频用：**不碰真实数据**。真实开发数据（`sidecar/data/`）在录制期间
整目录换出备份，换入一套全新灌好的虚构数据（虚构招标方「云澜市政务服务和数据管理局」
+ 虚构公司「星灵创科信息技术有限公司」），录完一键还原。

所有机构、人名、证号、金额、日期均为虚构，不对应任何真实主体。

## 一次性准备

```bash
# 1. 生成 9 份虚构 docx → demo/assets/（零依赖，重复跑覆盖生成）
cd sidecar && uv run python ../demo/gen_demo_docs.py

# 2. 灌库 → demo/demo-data/（起临时 sidecar；从真实库只读本机复制模型配置与 Key；
#    知识库 AI 抽取需要几分钟；真实数据此时仍在原位，不受影响）
uv run python ../demo/seed_demo.py
```

灌库结果：知识库 7 份材料（公司简介/资质证书/业绩合同×3/人员证书/财务审计）全部
解析并抽取完成，锚点核对通过的大多自动确认（个别留「待人工确认」反而能演示确认交互）；
素材库 1 份历史投标文件解析完成，**素材块留到录制时现场勾选**（这本身就是演示点）；
招标文件**不上传**，录制时拖入任务现场走全流程。

## 录制

```bash
./demo/record_env.sh on     # 备份真实数据 → 拷入演示数据 → 版本号临时提升（去更新红点）
npm run dev                 # 正常起 Tauri 开发窗口，录这里
```

录完（**务必**）：

```bash
./dev.sh stop               # 先停干净（脚本也会拦着没停就还原的情况）
./demo/record_env.sh off    # 还原真实数据 + 版本号，并按文件清单校验还原完整
./demo/record_env.sh status # 随时自查当前处于真实态还是演示态
```

`demo/demo-data/` 灌好后长期保留，可反复 `on` 复录（每次 on 都从灌好的干净状态开始，
上一次录制产生的任务/对话不会带进下一场）；不需要时整个删掉即可。

### 建议演示动线（约 8-12 分钟）

1. **首页**：拖入 `demo/assets/云澜市一体化政务服务平台运维及功能升级项目-招标文件.docx`
   ——以文件名直接建任务，展示任务即房间；
2. **解析概况确认门** → 确认后进入会话；
3. **分析**：「分析这份招标文件」→ 七节要点（资格条件/评分办法/废标条款都有实料，
   废标条款专门写了一节）、摆要点停轮、界面过目；
4. **目录**：「生成目录」→ 拆分确认 → 目录树产物、编辑体验；
5. **知识库**：侧栏切到知识库，展示 7 份星灵创科材料的类型徽章与时效状态；回会话问
   「我们公司有哪些资质证书，是否都在有效期内？」展示检索引用；
6. **素材库**：打开历史投标文件的目录树，勾选「总体技术方案」等章节建块 → 写正文时
   让它用素材；
7. **正文**：「开始写正文」→ 写作指引 → 关键事实与承诺（从知识库检索填值）→ 逐节生成
   → 合册整本；
8. 收尾展示产物面板/恢复点等按需。

### 录制画面注意

- 版本号已由 `on` 临时提到与官网一致（设置页显示真实发布号、无更新红点），`off` 自动还原；
- Tauri 壳日志（`~/Library/Logs/lingyan.ddmdj.com/`）在数据目录之外，如介意可在录制前
  清空该目录；
- 演示数据是全新目录：侧栏无历史任务/会话，正是干净的首录体验。

## 文件说明

| 文件 | 作用 |
|---|---|
| `gen_demo_docs.py` | 生成 9 份虚构 docx（python-docx，内容与日期锚点按知识库管线约束设计） |
| `seed_demo.py` | 灌库脚本（临时 sidecar + 本机复制模型配置 + 上传 + 轮询到抽取完成） |
| `record_env.sh` | `on`/`off`/`status` 换出/还原真实数据，含版本号临时提升与还原校验 |
| `assets/` | 生成的虚构文档（可入库复用） |
| `demo-data/` | 灌好的演示数据目录（gitignore，可整体搬运——库内无绝对路径） |

## 安全边界

- 真实数据只做整目录 `mv` 备份（`sidecar/data.real/`，gitignore），绝不删除/改写；
- API Key 只在本机从真实库读出、写进演示库，脚本不打印 Key（GET /settings 本就永不回读）；
- 已处于演示态时 `on` 拒绝、非演示态时 `off` 拒绝；开发进程未停时两个方向都拒绝；
- 忘了还原的兜底：`status` 一眼可查；`sidecar/data.real` 目录名本身就醒目。
